# ZEAL – IT Fest 2026

Official static website for **ZEAL**, the IT Fest hosted by Siddharth College (22–23 January 2026).

## Structure

```
├── index.html          # homepage — event listings
├── about.html           # about page
├── assets/
│   ├── css/             # stylesheets (home.css, event.css, about.css)
│   └── images/          # logo, backgrounds, event thumbnails
└── events/               # individual event detail pages
```

## Running locally

```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.

## Events

**Day 1:** Box Cricket, BGMI, Pixel Passage, Carrom, Tech Quiz, Bug Buster, Canva Design
**Day 2:** Website Making, Free Fire, Tech Meme, Chess, Active Trading, AI Treasure Hunt, Blurry Image
